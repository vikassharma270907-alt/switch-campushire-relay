Real-World Operational Crisis

The Campus Placement Crisis & The "All-or-Nothing" LLM Trap

Why traditional AI coding tools and manual spreadsheets break down under high stakes.

The Placement Office Nightmare

  • Manual Notice Decoding: Placement coordinators process 50+ unstructured job descriptions per season under tight deadlines.
  • Spreadsheet Formula Errors: A single mistaken filter excludes eligible students or invites campus legal disputes.
  • Terminal Isolation: Non-technical placement heads and HR officers cannot see or audit CLI coding tools.

The "All-or-Nothing" LLM Trap

  • Floating-Point Math Hallucinations: Frontier LLMs fail at reliable inequality checks on GPA cutoffs (e.g. 7.96 vs 8.00).
  • High Latency & Costs: Passing every trivial check to cloud models takes 2–5 seconds and burns API credits.
  • Prompt Injections: External recruiter notices carry malicious injection payloads that trick open agents.
Cognitive Systems Engineering

Kahneman Dual-Process Architecture (System 1 + System 2)

Decoupling fast neural reflexes from deliberative multi-agent collaboration.

System 1: Laya Fast Reflex Engine

<5ms Latency on CPU · Zero Token Cost

  • Pre-screens all recruiter notices for prompt injections and jailbreaks before LLM context ingestion.
  • Routes room messages and evaluates confidence: <0.75 triggers human clarification gates.
  • Scores candidate spoken answers against the STAR framework in sub-second time.

System 2: Switch AI Multi-Agent Bus

Deliberative Collaborative Rooms · Auditable State

  • Persistent PostgreSQL row-backed message bus with workspace Row-Level Security (RLS).
  • Drive Coordinator (@coord): Ingests notices and manages human approval gates.
  • Eligibility Auditor (@auditor): Runs deterministic Python math and issues SHA-256 receipts.
  • Career Coach (@coach): Quarantined in Room 2 for personalized candidate prep.
